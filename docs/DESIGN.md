# Grand Strategy — 설계서 (기획서 0.2 검토·수정판)

대상: Minecraft Java **26.3** / Fabric / **Kotlin**
상태: MVP 구현 단계 (이 문서와 함께 동작하는 코드가 들어 있음)

원 기획서(0.2)를 그대로 따르지 않고, 타당한 것은 유지하고 과한 것은 줄이고 빠진 것은 더했다. 무엇을 왜 바꿨는지는 각 절 끝의 **[판단]** 에 적었다.

## 0. "리버스 엔지니어링 리포지토리"를 어떻게 해석했나

GitHub에서 리버스 엔지니어링 분야 스타 1위는 NSA의 **Ghidra**(약 70k, Apache-2.0)다. 하지만 이 프로젝트에 Ghidra를 그대로 들이는 건 맞지 않는다.

- Ghidra는 네이티브 바이너리(x86/ARM 기계어)용이다. 마인크래프트는 JVM 바이트코드라서 Ghidra로 열면 정보가 오히려 줄어든다.
- **26.x부터 Mojang이 난독화를 없앴다.** 클래스·메서드 이름이 원본 그대로라 "복호화"할 것이 없다. 지금 필요한 건 *시그니처 확인*과 *동작 관찰*이다.

그래서 리버스 엔지니어링 **방법론**만 가져오고, 도구는 JVM에 맞는 것으로 바꿨다.

| 목적 | 도구 | 비고 |
| --- | --- | --- |
| 클래스·메서드 시그니처 확인 | `javap` (JDK 내장) | Loom이 만든 `minecraft-merged-deobf-26.3.jar` 대상. 이 코드의 모든 MC API 호출은 이 방법으로 확인한 것이다 |
| 메서드 본문 동작 분석 | Vineflower (Loom `genSources`) | Fabric 공식 디컴파일러 |
| 실행 중 동작 검증 | `runServer` + 콘솔 명령 | 분석 결과를 실행으로 확정 (원 기획서 15장) |

같은 폴더의 `courierpost` 프로젝트가 이미 이 방식으로 26.3 툴체인(Loom 1.17.19, Fabric API 0.161.0+26.3, JDK 25)을 실측 검증해 두었으므로 그대로 재사용했다.

**[판단]** "가장 유명한 RE 도구를 쓰는 것"보다 "RE의 원칙(관찰 → 가설 → 실행 검증)을 지키는 것"이 기획서 15장의 취지에 맞다.

## 2. 원 기획에서 바꾼 것 요약

| 기획서 | 이 설계 | 이유 |
| --- | --- | --- |
| "AI 국가 시스템" | **다층 규칙 기반 알고리즘** (LLM·머신러닝 없음) | 사용자 판단과 같다. 결정적이고 테스트할 수 있으며 서버 비용이 0에 가깝다 (7절) |
| 바닐라 마을 = 국가 | 바닐라 마을 = **자유 마을**(독립 세력, 국가가 아님) | 사용자 요구. 국가와 다른 규칙을 적용한다 (5절) |
| 실시간 개별 시뮬레이션 | **턴제 추상 시뮬레이션** + 월드에서 보이는 결과 | 기획서 2.3 단서 조항 그대로. 기본 1턴 = 10초 |
| 9가지 GUI 화면 | 상자 GUI 6개 + 명령 | 마인크래프트 고유 UI를 지키고 클라이언트 모드 없이 동작 |
| 실제 엔티티 군대 | **MVP는 추상 전투** + 플레이어가 전선에 있으면 보정 | 엔티티 군대는 TPS를 잡아먹는다 (courierpost 측정: 닭 1000마리에 TPS 20 → 4.45) |
| 기술 8분야 | 8분야 유지, 각 분야 효과는 **한 줄 공식** | 간단하게. 효과가 수치로 바로 보인다 |
| 다국어 | 한국어만 | 간단하게 |

**추가한 것**

1. **자유 마을의 흡수·반란 순환** — 사절 → 영향력 100 → 평화적 편입, 정복은 평판 손해, 불안정한 국가에서는 마을이 독립한다.
2. **국가 분열(내전)** — 안정도가 바닥이고 영토가 넓으면 변방이 떨어져 나가 새 국가가 되고 원래 국가와 전쟁한다. 월드박스식 흥망성쇠를 만드는 핵심 장치.
3. **휴전 조약** — 평화 직후 바로 재침공하는 진동을 막는다.
4. **실물 납부** — 플레이어가 손에 든 밀·원목·돌·철·금을 국고에 넣을 수 있다. 실제 월드 활동과 국가 경제를 잇는 가장 단순한 고리.
5. **국경 알림** — 청크 경계를 넘으면 액션바에 "OO 왕국 영토"가 뜬다.
6. **수도 표식** — AI 국가의 수도 청크가 처음 로드되면 지표에 국가색 깃발이 선다.
7. **자동 통치** — 플레이어 국가도 `/gs auto`로 AI에 맡기고 자리를 비울 수 있다.
8. **성능 계측** — 턴당 처리 시간 평균·최대를 기록한다 (`/gs admin perf`).

## 3. 구조

```
com.grandstrategy
├── GrandStrategy          진입점. 이벤트 등록, 수명주기
├── sim/                   순수 Kotlin. 마인크래프트 클래스를 import하지 않는다 → 단위 테스트 가능
│   ├── Model              국가, 자유 마을, 전쟁, 관계, 사건 (직렬화 대상)
│   ├── Balance            모든 수치 상수 한 곳
│   ├── Chunks             청크 키 패킹, 이웃
│   ├── Economy            생산·소비·인구·연구·안정도
│   ├── Actions            행동 정의 + 검증·실행 (플레이어와 AI가 같은 경로를 탄다)
│   ├── Ai                 다층 의사결정
│   ├── Diplomacy          호감도·조약
│   ├── Warfare            전투·점령·평화·멸망
│   ├── Settlements        자유 마을
│   ├── Simulation         턴 진행, 국가 생성·분열
│   └── Names              국가 이름 생성
└── mc/                    마인크래프트 연결부
    ├── BiomeTerrain       바이옴 → 지형 분류
    ├── Storage            저장·불러오기
    ├── WorldHooks         마을 발견, 주민 수, 수도 깃발, 국경 알림
    ├── Runtime            턴 스케줄링, 속도, 계측
    ├── Commands           /gs
    ├── Texts              채팅 텍스트 양식
    └── gui/Menus          상자 GUI
```

**[판단]** 시뮬레이션을 MC와 완전히 분리한 덕분에, 서버를 띄우지 않고도 "20개국 × 500턴" 같은 시나리오를 테스트에서 돌릴 수 있다. MC 버전이 바뀌어도 고칠 곳이 `mc/`로 한정된다.

서버가 모든 판정을 한다. 클라이언트는 명령과 GUI 클릭만 보내고, 국가 데이터는 서버에서 검증한 행동으로만 바뀐다 (기획서 11장).

`environment: "*"` — 싱글플레이(통합 서버)에서도 동작하고, 전용 서버라면 접속자는 모드 없이 바닐라 클라이언트로 들어온다. GUI가 전부 바닐라 상자 메뉴라서 가능하다.

## 4. 국가

| 데이터 | 설명 |
| --- | --- |
| id, 이름, 색 | 색은 바닐라 염료 16색 중 하나. 양털·색유리·깃발로 표현 |
| 수도 | 청크. 함락되면 다른 영토로 옮기고, 영토가 없으면 멸망 |
| 영토 | 청크 집합 |
| 인구 | 주거 한도 = 영토 × 8 + 시설 × 2 + 편입 마을 인구 |
| 비축 | 식량 / 목재 / 석재 / 철 / 금 |
| 시설 | 농장, 벌목장, 채석장, 광산, 시장, 도서관, 병영, 성벽 (총수 ≤ 영토 수) |
| 기술 | 8분야 레벨 + 연구 진행도 + 연구 중인 분야 |
| 군사 | 병력 수 → 전투력은 기술·병영·안정도·철 비축으로 보정 |
| 안정도 | 0–100. 목표치를 향해 매 턴 10%씩 이동 |
| 정책 | 균형 / 경제 / 군사 / 학문 / 확장 |
| 통치자 | 플레이어 UUID 또는 없음(AI). 자동 통치 여부 |
| AI 성향 | 공격성, 팽창욕, 외교성 (생성 시 무작위, 0–1) |

### 영토 규칙
- 내 영토와 맞닿은 청크만 확장할 수 있다.
- 바다는 차지할 수 없다. 자유 마을 땅은 확장으로 차지할 수 없다 (사절 또는 정복만).
- 확장 비용은 영토가 클수록 오른다 (√영토). 행정 기술과 확장 정책으로 줄어든다.
- 과확장: 영토가 `20 + 행정×5`를 넘으면 안정도 목표가 내려간다.

## 5. 자유 마을 (바닐라 마을)

바닐라가 생성한 마을은 **국가가 아니다.** 다음이 다르다.

| | 국가 | 자유 마을 |
| --- | --- | --- |
| 확장 | 함 | 안 함 (구조물 경계만 차지) |
| 외교·전쟁 선포 | 함 | 안 함 |
| 기술 연구 | 함 | 안 함 |
| 인구 | 시뮬레이션 수치 | **실제 주민 엔티티 수** (청크 로드 시 갱신) |
| 방어력 | 병력 × 보정 | 주민 수 + 철 골렘 × 10 |
| 다른 세력과의 관계 | 호감도 (−100–100) | 국가별 **영향력** (0–100) |

상호작용:

1. **교역** — 6청크 안에 있는 국가는 매 턴 금 수입을 얻고 영향력이 조금 오른다. 시장이 있으면 더 오른다.
2. **사절** — 금 15를 써서 영향력 +15. 영향력이 100이 되면 **평화적으로 편입**된다.
3. **정복** — 전투력이 방어력의 2배를 넘어야 한다. 성공하면 편입되지만 안정도 −10, 다른 모든 국가의 호감도 −10, 마을 인구 −30%.
4. **편입 후** — 마을 땅이 국가 영토가 되고 인구가 주거 한도에 더해진다. 소유국 안정도가 30 아래면 충성도가 깎이고, 0이 되면 **독립**한다.

발견: 청크가 로드될 때 그 청크의 구조물 시작점에 마을이 있으면 등록한다. 플레이어가 아직 가지 않은 곳은 서버 시작 직후 `findNearestMapStructure`로 몇 군데 탐색해 둔다 (한 번에 한 번씩, 틱을 나눠서).

## 6. 경제 · 기술

모든 수치는 `Balance.kt` 한 곳에 있다.

**생산** (청크당, 턴당) = 지형 기본값 × 노동력 × (1 + 0.2 × 해당 시설) × 기술 보정 × 정책 보정 × 안정도 보정
- 지형은 바이옴에서 나온다: 평원은 식량, 숲·타이가는 목재, 산·언덕은 석재·철, 악지·사막은 금.
- 노동력 = min(1, 인구 / (영토 × 3)).
- 세금: 인구 × 0.02 금.

**소비**: 식량 = 인구 × 0.1 + 병력 × 0.1, 금 = 병력 × 0.05 + 영토 × 0.02. 식량이 0이 되면 인구 −5%, 안정도 하락.

**기술** (레벨당 효과)

| 분야 | 아이콘 | 효과 |
| --- | --- | --- |
| 농업 | 밀 | 식량 +10% |
| 광업 | 철 곡괭이 | 석재·철·금 +10% |
| 산업 | 모루 | 목재 +5%, 시설 효율 +5% |
| 물류 | 광산 수레 | 확장 비용 −8%, 전투 보급 +5% |
| 행정 | 책과 깃펜 | 안정도 목표 +3, 과확장 한도 +5 |
| 교육 | 책장 | 연구 속도 +15% |
| 군사 | 철 검 | 전투력 +10% |
| 건설 | 벽돌 | 시설 비용 −8%, 성벽 효과 +5% |

다음 레벨 비용 = 40 × (레벨+1)^1.6 연구점.

## 7. AI — 다층 규칙 알고리즘

학습 모델 없이 4층으로 쌓는다. 같은 입력이면 같은 결정이 나온다 (턴 번호로 시드를 정하는 난수만 섞임).

```
1층 인지     : 자원별 수지·남은 턴수, 이웃별 위협(상대 전투력 × 적대도 ÷ 내 전투력),
              기회(가장 약한 적대 이웃), 확장 후보 청크, 가까운 자유 마을
     ↓
2층 자세     : 성장 / 안정화 / 군비 / 전쟁 / 팽창 중 하나. 히스테리시스로 매 턴 흔들리지 않게 한다
     ↓
3층 효용 계산 : 후보 행동마다 점수 = 필요도 × 자세 가중치 × 성향 가중치 − 비용 부담
              (시설 건설, 확장, 징병, 연구 분야 선택, 사절, 정복, 조약 제안, 선전포고, 평화 제안, 정책 변경)
     ↓
4층 실행     : 상위 N개를 플레이어와 똑같은 검증 경로로 실행. 실패하면 다음 후보로
```

모든 결정은 이유와 함께 사건 기록에 남는다. 예: `철의 왕국이 광산을 지었다 (철 비축 3턴분)`.

선전포고 조건(모두 충족): 국경 접함, 휴전·불가침 아님, (호감도 < −30 또는 공격성 높고 상대보다 1.5배 강함), 이미 진행 중인 전쟁 없음, 식량 여유 있음.

## 8. 외교

- 호감도 −100–100. 매 턴 2%씩 0으로 돌아가고, 국경 마찰(−), 교역 조약(+), 동맹(+), 공동의 적(+), 전쟁 중(−)으로 움직인다.
- 조약: **불가침**, **교역**(양국 금 수입), **동맹**(방어전에 자동 참전), **휴전**(평화 후 30턴, 전쟁 불가).
- AI는 호감도와 위협을 보고 제안을 받아들인다. 플레이어에게 오는 제안은 채팅에 **[수락] [거절]** 버튼으로 뜬다.
- 불가침을 깨고 선전포고하면 모든 국가의 호감도 −15, 자국 안정도 −10.

---

## 9. 전쟁

MVP는 **추상 전투**다.

- 매 턴 각 전쟁에서 양측이 전선(적 영토와 맞닿은 청크) 하나씩을 골라 공격한다.
- 전투력 = 병력 × 군사 기술 × 병영 × 안정도 × 보급(식량·철) × 무작위(0.8–1.2). 방어 측은 성벽과 홈 이점(×1.15)을 받는다.
- **실제 월드 연결**: 해당 청크 근처(전선 청크 주변 1청크)에 그 국가 소속 플레이어가 서 있으면 1명당 +25%. 플레이어가 전선에 가는 것이 의미가 있다.
- 이긴 쪽이 청크를 가져간다. 진 쪽 병력 −10%, 이긴 쪽 −5%. 전쟁 점수와 피로도가 쌓인다.
- 수도 함락 → 수도 이전, 안정도 −20, 점수 +25. 영토가 0이 되면 **멸망**.
- 피로도가 높거나 크게 지고 있으면 AI가 평화를 제안한다. 평화 후 30턴 휴전.

**로드맵 (MVP 이후)**: 플레이어 근처 전투를 실제 엔티티로 보여주기 (약탈자 대 철 골렘 같은 바닐라 몹, 태그로 관리, 수 제한), 부대 단위 이동, 스타크래프트식 직접 지휘.

## 10. UI (마인크래프트 고유 디자인만)

전부 **바닐라 상자 메뉴**다. 아이콘은 바닐라 아이템, 정보는 아이템 이름과 툴팁. 빈칸은 회색 색유리 판.

| 화면 | 열기 | 내용 |
| --- | --- | --- |
| 국가 | `/gs` | 비축(밀·원목·조약돌·철괴·금괴), 인구, 병력(철 검), 안정도(종), 기술(책), 정책 |
| 지도 | 국가 화면 → 지도 | 플레이어 주변 9×5 청크. 국가색 색유리, 수도는 신호기, 자유 마을은 종, 나는 나침반 |
| 연구 | 국가 화면 → 책 | 8분야, 클릭하면 연구 분야 지정, 진행 중인 분야는 반짝임 |
| 건설 | 국가 화면 → 제작대 | 시설 8종, 클릭하면 건설, 비용은 툴팁 |
| 외교 | 국가 화면 → 지도 그림 | 국가별 양털, 호감도·조약·전쟁 상태, 클릭하면 그 국가에 대한 행동 메뉴 |
| 기록 | 국가 화면 → 종이 | 최근 사건 |

HOI 지도, 문명 도시 화면, 스타크래프트 지휘 UI를 흉내 내지 않는다 (기획서 2.2).
