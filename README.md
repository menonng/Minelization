# Grand Strategy

마인크래프트 기본 월드에서 여러 나라가 스스로 자라고, 교역하고, 연구하고, 전쟁한다. 플레이어는 나라 하나를 맡아 운영하거나 지켜본다. 바닐라 마을은 나라가 아닌 **자유 마을**로 남는다.

설계와 판단 근거는 [docs/DESIGN.md](docs/DESIGN.md).

## 요구사항

| 항목 | 버전 |
| --- | --- |
| Minecraft | 26.3 |
| Fabric Loader | 0.19.3 이상 |
| Fabric API | 0.161.0+26.3 |
| Fabric Language Kotlin | 1.14.2+kotlin.2.4.21 |
| Java | 25 이상 |

싱글플레이: 위 모드를 클라이언트 `mods/`에 넣는다.
전용 서버: 서버 `mods/`에만 넣는다. 접속자는 모드 없이 바닐라 클라이언트로 들어온다 (GUI가 전부 바닐라 상자 메뉴다).

## 빌드

```bash
./gradlew build
```

`gradle.properties`의 `org.gradle.java.installations.paths`는 이 개발 PC의 JDK 25 경로다. 다른 PC에서는 자기 JDK 25 경로로 바꾸거나 줄을 지운다.

산출물은 `build/libs/`, `./gradlew collect`로 `dist/`에 모인다. 시뮬레이션 단위 테스트는 `./gradlew test`.

개발 서버: `./gradlew runServer` (실행 폴더 `run/`).

## 시작하기

1. 월드를 처음 열면 스폰 주변에서 바닐라 마을을 몇 곳 찾고, 그다음 AI 나라 6개를 세운다 (약 10초).
2. `/gs`로 메뉴를 연다. 소속이 없으면 나라 목록이 나온다. 좌클릭으로 통치자가 되거나, "여기에 건국"으로 새 나라를 세운다.
3. 1턴은 10초다. 영토를 넓히고(`/gs claim` 또는 지도에서 클릭), 시설을 짓고, 연구하고, 외교한다.
4. 밀·원목·조약돌·철괴·금괴를 손에 들고 `/gs deposit`하면 국고에 들어간다.
5. 같은 나라의 국민(`/gs join`)이 전선 근처에 서 있으면 그 전투에서 1명당 전투력 +25%.

관찰만 하려면 `/gs observe` (AI 판단까지 보려면 `/gs observe all`).

## 명령

| 명령 | 설명 |
| --- | --- |
| `/gs` | 국가 메뉴 |
| `/gs list` · `info [국가]` · `here` · `log` | 조회 |
| `/gs found <이름>` · `pick <국가>` · `join <국가>` · `leave` · `rename <이름>` · `auto` | 소속과 통치 |
| `/gs claim` · `build <시설>` · `recruit <수>` · `research <분야>` · `policy <정책>` · `deposit` | 내정 |
| `/gs envoy` · `conquer` | 가장 가까운 자유 마을에 사절 / 정복 |
| `/gs treaty <종류> <국가>` · `untreaty <종류> <국가>` · `war <국가>` · `peace <국가>` · `accept <id>` · `decline <id>` | 외교 |
| `/gs admin speed <틱>` · `pause` · `resume` · `step [턴]` · `seed <수>` · `perf` · `save` | 관리 (OP) |

## 저장

`<월드>/data/grandstrategy.json`. 5분마다, 그리고 서버가 꺼질 때 저장한다. 임시 파일에 쓴 다음 원자적으로 교체한다. 파일이 깨져 있으면 사본을 남기고 새로 시작한다.

## 검증한 것 (2026-10-16)

- `./gradlew build` 성공, 단위 테스트 6개 통과
  - 8개국 400턴: 영토 72 → 1101청크, 전쟁·조약·내전·멸망 발생
  - 10개국 300턴 동안 매 턴 영토 소유 일관성 (소유 지도 = 국가별 영토, 수도 ⊂ 영토)
  - 저장 → 불러오기 왕복 후 다음 턴 결과가 원본과 같음 (결정성)
  - 자유 마을 사절 7회 → 평화 편입, 마을 땅이 나라 영토로
- 26.3 전용 서버 실기동 (`runServer`, 일반 지형)
  - 스폰 주변 바닐라 마을 4곳 탐지, AI 나라 6개 생성
  - 1016턴 진행: 전쟁, 수도 함락, 멸망(세덴벨 대공국), 내전으로 새 나라(타온 자유국) 등장
  - 턴 처리 평균 1.76ms, 최대 25.6ms (첫 턴의 지형 샘플링 포함). 서버 틱 예산 50ms 대비 여유
  - 재시작 후 615턴 상태 그대로 복원
  - 수도 청크 로드 시 국가색 깃발 설치 확인 (`data get block` → `minecraft:banner`)
  - 마을 청크 로드 시 실제 주민 수로 인구 갱신 (주민 5 → 인구 25)

## 검증하지 못한 것

- **실제 클라이언트로 접속해 GUI를 눌러본 적이 없다.** 상자 메뉴 클릭 가로채기, 아이콘·툴팁 표시, 액션바 국경 알림, 채팅 [수락]/[거절] 버튼은 코드와 컴파일까지만 확인했다.
- 플레이어 명령(`found`, `claim`, `deposit` 등)은 서버 콘솔에서 실행할 수 없어(플레이어 필요) 실서버에서는 돌려보지 않았다. 같은 로직을 단위 테스트에서 검증했다.
- 여러 플레이어가 동시에 나라를 운영하는 상황.
- 몇 시간 이상의 장시간 운영.
