# Grand Strategy

마인크래프트 기본 월드에서 여러 나라가 스스로 자라고, 교역하고, 연구하고, 전쟁한다. 플레이어는 나라 하나를 맡아 운영하거나 지켜본다. 바닐라 마을은 나라가 아닌 **자유 마을**로 남는다.

설계와 판단 근거는 [docs/DESIGN.md](docs/DESIGN.md), 앞으로의 계획은 [docs/ROADMAP.md](docs/ROADMAP.md).

## 요구사항

| 항목 | 버전 |
| --- | --- |
| Minecraft | 26.3 |
| Fabric Loader | 0.19.3 이상 |
| Fabric API | 0.161.0+26.3 |
| Fabric Language Kotlin | 1.14.2+kotlin.2.4.21 |
| Java | 25 이상 |

싱글플레이: 위 모드를 클라이언트 `mods/`에 넣는다.
전용 서버: 서버 `mods/`에만 넣는다. 접속자는 모드 없이 바닐라 클라이언트로 들어온다 (GUI가 전부 바닐라 상자 메뉴다).

## 빌드

```bash
./gradlew build
```

`gradle.properties`의 `org.gradle.java.installations.paths`는 이 개발 PC의 JDK 25 경로다. 다른 PC에서는 자기 JDK 25 경로로 바꾸거나 줄을 지운다.

산출물은 `build/libs/`, `./gradlew collect`로 `dist/`에 모인다. 시뮬레이션 단위 테스트는 `./gradlew test`.

개발 서버: `./gradlew runServer` (실행 폴더 `run/`).

### 테스트 서버에 설치

```bash
./gradlew deploy -PserverDir=D:/my-server
```

빌드한 jar를 `<서버>/mods`에 넣고, 이전 빌드(`grandstrategy-*.jar`)는 지운다. 다른 모드는 건드리지 않는다. 매번 경로를 쓰기 싫으면 저장소 루트에 `local.properties`를 만들고 `serverDir=D:/my-server`를 적는다 (git에 올라가지 않는다). 환경 변수 `MINELIZATION_SERVER`도 된다. 서버가 켜져 있으면 jar가 잠겨 실패할 수 있으니 서버를 끈 뒤 실행한다.

## 시작하기

1. 새 월드를 열면 관리자에게 **세계 준비 화면**이 뜬다. 크기(500 ~ 5000, 5단계)와 미리 생성·조물주 모드를 고르면 월드 경계가 생기고, 바닐라 마을을 찾은 뒤 크기에 맞는 수의 AI 나라가 세워진다. [Chunky](https://modrinth.com/mod/chunky)를 함께 설치하면 미리 생성이 훨씬 빠르다 (선택).
2. `/gs`로 메뉴를 연다. 소속이 없으면 나라 목록이 나온다. 좌클릭으로 통치자가 되거나, "여기에 건국"으로 새 나라를 세운다.
3. 1턴은 10초다. 영토를 넓히고(`/gs claim` 또는 지도에서 클릭), 시설을 짓고, 연구하고, 외교한다.
4. 밀·원목·조약돌·철괴·금괴를 손에 들고 `/gs deposit`하면 국고에 들어간다.
5. 같은 나라의 국민(`/gs join`)이 전선 근처에 서 있으면 그 전투에서 1명당 전투력 +25%.

관찰만 하려면 `/gs observe` (AI 판단까지 보려면 `/gs observe all`).

## 밸런스 실시간 조정

수치는 전부 `config/grandstrategy/balance.json`에 있다 (첫 실행 때 기본값으로 생성). 인구 증가율, 자원 소비, 지형별 생산량, 시설·확장·징병 비용, 연구 비용, 교역 범위, AI 임계값과 선전포고 조건 등.

1. 서버가 켜진 채로 파일을 고친다.
2. 게임에서 `/gs admin reload`.
3. 바뀐 값 목록이 채팅에 나오고 다음 턴부터 바로 적용된다.

형식이 틀리거나 값이 말이 안 되면(음수 비용, 0 이하 노동자 수 등) 거부하고 기존 값을 유지한다. 빠진 키는 기본값을 쓴다. 코드 자체(새 기능, 로직 변경)는 이걸로 바뀌지 않는다. 그건 `./gradlew deploy` 후 서버 재시작이 필요하다.

## 주민 개체 (인구 = 실제로 보이는 주민)

나라의 인구만큼 주민이 존재하고 실제로 걸어 다닌다. 서버에는 엔티티를 만들지 않고 데이터로만 두며, 플레이어 근처 150명만 패킷으로 보여준다. 개체 100,000명에서도 TPS 20을 측정했다 (자세한 내용은 [docs/ROADMAP.md](docs/ROADMAP.md) 1.3).

| 명령 | 설명 |
| --- | --- |
| `/gs admin agents` | 개체 수, 표시 수, 초당 패킷, 처리 시간, MSPT/TPS |
| `/gs admin agents benchmark <수>` · `off` | 인구와 상관없이 개체 수 고정 (부하 시험) / 해제 |
| `/gs admin agents vanilla <수>` · `clearvanilla` | 비교용 바닐라 주민 소환 / 제거 |

`balance.json`의 `agents` 항목: `perPopulation`(인구 1당 개체), `max`(전체 상한), `spawnPerTurn`, `visibleRadius`, `maxVisiblePerPlayer`.

## 세계 지도

`M` (또는 `/gs map`). 서버가 미리 생성된 범위를 바닐라 지도 색과 높이 음영으로 그려 타일로 보내고, 클라이언트가 그 위에 나라 영토·국경·이름, 수도·도시, 플레이어를 겹쳐 그린다. 끌어서 이동, 휠로 확대·축소. 자세한 내용은 [docs/ROADMAP.md](docs/ROADMAP.md) 1.8.

## 작업 지정 모드 (건축·철거)

관전자 모드에서 `B`. 드래그로 영역을 잡고 건축(바닐라 마을 건물 126종)·성벽·철거·평탄화를 지시하면 건축가 주민(징용 시 일반 국민도)이 걸어가 한 블록씩 작업한다. 건물을 클릭하면 외곽을 잇는 상자를 하나의 건물로 인식해 철거·용도 지정을 할 수 있다. 자세한 조작은 [docs/ROADMAP.md](docs/ROADMAP.md) 1.5. 바닐라 클라이언트는 `/gs work ...` 명령.

## 컷신 (클라이언트 모드)

같은 jar를 클라이언트에도 넣으면 컷신이 나온다. 클라이언트에 모드가 없으면 바닐라 제목·부제목으로 대신 알린다.

| 컷신 | 누구에게 | 내용 |
| --- | --- | --- |
| 건국 | 나라를 세운 플레이어 | 플레이어 시점에서 빠져나와 수도를 돌며 상승, 국경을 국가색 빛 기둥으로 표시, 불꽃, 국호 |
| 수도 함락 | 수도를 잃은 나라의 국민 | 먼 곳에서 수도로 밀고 들어가는 카메라, 폭발·연기·불길, 화면 흔들림, 붉은 비네트 |
| 멸망 | 모든 접속자 | 화면이 어두워지고 국기가 흔들리다 산산조각, 국호에 취소선 |

재생 중에는 HUD·손·토스트가 숨겨지고, 서버에서는 해당 플레이어가 피해를 받지 않고 몹이 노리지 않으며 제자리에 고정된다. 수도가 먼 곳이면 잠시 관전자 모드로 그곳에 옮겨졌다가 끝나면 원래 위치·게임 모드로 돌아간다(도중에 서버가 꺼져도 다음 접속 때 복구). `Esc`로 건너뛸 수 있다. 멸망 컷신은 30초에 한 번까지만 나온다.

시험 재생: `/gs admin cutscene <founding|capital_fall|destruction> <플레이어>`

개발용 클라이언트: `./gradlew runClient`가 `localhost:25565`에 `Tester`로 자동 접속한다. `-Pcapture=true`를 붙이면 컷신 중 0.75초마다 `run/client/screenshots/`에 프레임을 저장한다. 예시 프레임은 `docs/cutscenes/`.

## 저장

`<월드>/data/grandstrategy.json`. 5분마다, 그리고 서버가 꺼질 때 저장한다. 임시 파일에 쓴 다음 원자적으로 교체한다. 파일이 깨져 있으면 사본을 남기고 새로 시작한다.

## 검증한 것 (2026-10-16)

- `./gradlew build` 성공, 단위 테스트 6개 통과
  - 8개국 400턴: 영토 72 → 1101청크, 전쟁·조약·내전·멸망 발생

  - 저장 → 불러오기 왕복 후 다음 턴 결과가 원본과 같음 (결정성)
  - 자유 마을 사절 7회 → 평화 편입, 마을 땅이 나라 영토로
- 26.3 전용 서버 실기동 (`runServer`, 일반 지형)
  - 스폰 주변 바닐라 마을 4곳 탐지, AI 나라 6개 생성
  - 1016턴 진행: 전쟁, 수도 함락, 멸망(세덴벨 대공국), 내전으로 새 나라(타온 자유국) 등장
  - 턴 처리 평균 1.76ms, 최대 25.6ms (첫 턴의 지형 샘플링 포함). 서버 틱 예산 50ms 대비 여유
  - 재시작 후 615턴 상태 그대로 복원
  - 수도 청크 로드 시 국가색 깃발 설치 확인 (`data get block` → `minecraft:banner`)
  - 마을 청크 로드 시 실제 주민 수로 인구 갱신 (주민 5 → 인구 25)

## 검증하지 못한 것

- **실제 클라이언트로 접속해 GUI를 눌러본 적이 없다.** 상자 메뉴 클릭 가로채기, 아이콘·툴팁 표시, 액션바 국경 알림, 채팅 [수락]/[거절] 버튼은 코드와 컴파일까지만 확인했다.
- 플레이어 명령(`found`, `claim`, `deposit` 등)은 서버 콘솔에서 실행할 수 없어(플레이어 필요) 실서버에서는 돌려보지 않았다. 같은 로직을 단위 테스트에서 검증했다.
- 여러 플레이어가 동시에 나라를 운영하는 상황.
- 몇 시간 이상의 장시간 운영.
